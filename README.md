# Crispy-JNath-Chips
This PHP-based web application includes an iconic concept from The PBB 3.0 Collab that Jeo and Nathan made in "Bahay ni Kuya" that's called "Crispy JNath Chips." The user is allowed to browse the products that has the discount, tax, and total amount—which shows an example usage of Functions. They can also fill out a form to order their chips, and receive a receipt that shows their final order. Here is the code that made the web application for JNath Chips possible.
